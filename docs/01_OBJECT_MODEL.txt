REVIEW CHECKLIST 1: OBJECT MODEL
================================

Objects are in dependency order: a parent is always checked before the objects that look up to it, so each relationship is checked once, from the child side, against a parent already signed off.

Each object carries its own trigger, handler and handler test, so an object is finished only when what enforces it on save is finished too.
