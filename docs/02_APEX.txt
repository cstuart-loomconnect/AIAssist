REVIEW CHECKLIST 2: APEX BY FEATURE
===================================

Trigger handlers are not here: each is checked with its object in the object model checklist.

Sections are in call order, lowest layer first, so a class is checked after the classes it depends on. Each class is listed with its sharing declaration, size and stated purpose, and its test class sits directly beneath it.
