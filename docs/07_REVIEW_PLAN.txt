REVIEW PLAN - NEW LWCs AND APEX CLASSES (branch integration-testing, 2026-10-22)

How to use this: each section is one tab (or one shared layer) and can be reviewed on its own.
Within a section, read in this order: Apex DataStructure -> Controller -> EditorService/other
services -> parent LWC -> child LWCs -> tests. "Lines" are js+html+css for an LWC and .cls for a
class. Every Apex class has a matching *Test class unless noted.

Review order suggestion: 1 (smallest, sets the pattern every other tab copies), then 2, 6, 3, 4, 5, 7.
