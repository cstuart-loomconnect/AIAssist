REVIEW CHECKLIST 1: OBJECT MODEL
================================

Part 1 of 3. Start here. Objects are in dependency order: a parent is always reviewed before the objects that look up to it, so each relationship is checked once, from the child side, against a parent you have already signed off.

Each object carries its own trigger, handler and handler test, so an object is finished only when what enforces it on save is finished too.


1.1 SHARED BUILDING BLOCKS
--------------------------

Reviewed first because objects below refer to them.

Global value sets:

[ ] AIChannel: Record Page Chat, Utility Bar, Mobile
[ ] AIViolationType: UnauthorizedDataAccess, UnauthorizedWorkflowAction, UsageLimitExceeded, PIIMaskingFailure, ConfigurationViolation, AIFlaggedIntent

Standard object extension:
