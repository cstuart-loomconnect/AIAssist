Update these docs

The data model pages are generated from the object metadata. After changing objects or fields, run: 

npm run docs:build    # regenerates site/
npm run docs:serve    # preview at http://localhost:8080

Where things live:

  • scripts/docs/pages/ - the text of the Home, Architecture, Security and Develop pages (plain HTML).
  • scripts/docs/content/navigation.mjs - the list of screens shown under User interface.
  • scripts/docs/templates/ - the page layout and the screen page template.
  • site/ - the generated output. Do not edit it by hand.

Pushing to master publishes the site through GitHub Pages.
