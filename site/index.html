AI Assist

A Salesforce package called AI Assist that puts configurable AI agents into Lightning Experience: chat with an agent on a record page, utility bar or mobile, backed by your choice of model, prompt template, data sources and workflow actions.

How it fits together

  1. ConfigureAn admin creates an agent with a model, a prompt template, data sources and workflow actions.
  2. ChatA user sends a message. It is stored, then processed asynchronously.
  3. ProtectPII is masked before the message leaves Salesforce and restored in the reply.
  4. CallThe provider is called. The model may fetch data or suggest an action.
  5. GovernUsage policies cap consumption; logs, feedback and retention keep it auditable.
