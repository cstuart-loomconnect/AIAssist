Objects

ObjectPurpose
AI Agent AssignmentGrants a user access to an agent when its access mode is Assigned Users Only.
AI Agent Data SourceJunction: which data sources an agent may call.
AI Agent Workflow ActionJunction: which workflow actions an agent may suggest.
AI AgentAn assistant a user can chat with: persona, access mode, conversation limits and retention, tied to a model and a prompt template.
AI Data SourceA tool that fetches data for the model, e.g. a SOQL template, Apex or Flow.
AI Model ConfigurationA connection to an AI provider: named credential, model identifier, temperature and output limits.
AI Prompt TemplateThe system prompt an agent answers with, including merge fields. Can be tested with Try It.
AI Prompt Test MessageA saved test message used to try a prompt template.
AI Workflow ActionA tool that does something on the user's behalf, e.g. an Apex action or a Screen Flow.
