Security

Permission set For Grants
AIAssistUser Everyone who chats Use the chat window and own conversations.
AIAssistSuperUser Power users and support User access plus review of logs, usage and conversations.
AIAssistAdminUser Administrators Configure agents, models, templates, tools, policies, the PII registry and settings.

Rules

  • Conversations are private. Their sharing model is Private; sharing goes through AIConversationShareService.
  • Agent access. Assigned Users Only (default) limits an agent to users on its Agent Assignments; All AI Assist Users opens it to everyone with the user permission set.
  • Child records follow their parent. Messages, assignments, junctions and PII child objects are Controlled by Parent.
  • PII masking happens before any text is sent to a provider.
