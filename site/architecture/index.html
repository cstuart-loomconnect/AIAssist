Architecture

Built in layers; each layer depends only on those above it.

Layer What it does Key classes
Object model Custom objects, metadata types, settings, validation rules and triggers. 28 objects
Foundation Constants, settings, logging, schema helpers. AIAssistApplicationConstants AIAssistSettingsService AIPlatformLogManager AISchemaHelper
Agents and prompts Agent lifecycle, prompt templates and merge fields. AIAgentManager AIPromptTemplateService AIPromptMergeFieldService
Messaging Validates, queues and processes each message and records the outcome. AIMessageValidator AIMessageProcessingQueueable AIMessageOutcomeService AIConversationLockService
Providers One request builder and response handler per provider behind shared interfaces. IAIProviderRequestBuilder IAIProviderResponseHandler AIAnthropic… AIOpenAi…
Tools Data sources and workflow actions the model can use. AIDataSourceDispatcher AIWorkflowActionDispatcher AISoqlTemplateRunner
PII Registry, classification and pseudonymisation. AIPiiFieldRegistry AIPiiPseudonymizationService AIPiiRegistrySyncWorker
Usage Policies and daily usage counting. AIUsagePolicyService AIUsageLimitService AIUsageService
Maintenance Idle, retention and recalculation jobs. AIMaintenanceScheduler AIConversationIdleBatch AIConversationRetentionBatch
User interface One LWC family per screen; each admin tab has a controller, editor service and data structure. see User interface

Extension points

New providers, data sources and workflow actions plug in through interfaces: IAIProviderRequestBuilder IAIProviderResponseHandler IAIDataSourceExecutor IAIDataSourceInputDescriber IAIWorkflowActionExecutor IAIWorkflowActionInputDescriber
