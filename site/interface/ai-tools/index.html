AI Tools

Data sources (information the model can fetch) and workflow actions (things it can suggest or do), each built with a guided wizard and tested before use.

Behaviour worth knowing

  • Each data source and workflow action records its last test result and time.
  • "Run as" another user is a field-access check from that user's permission sets, not real impersonation.
  • A SOQL template with no LIMIT gets one added (warning); a LIMIT over 200 is an error.

Objects it works with

  • AI Data Source AIDataSource__c
  • AI Workflow Action AIWorkflowAction__c
  • AI Agent Data Source AIAgentDataSource__c
  • AI Agent Workflow Action AIAgentWorkflowAction__c
