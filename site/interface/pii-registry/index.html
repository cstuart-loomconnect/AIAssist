PII Registry

Choose which objects are scanned, review how each field is classified, test masking, and see unprotected fields.

Behaviour worth knowing

  • A manual override on a field is kept when the sync worker re-classifies; Reset re-classifies it.
  • A registry whose Active box is off stops masking.
  • A registry fails (and is retried) when an object has more fields than its Max Fields To Query.
