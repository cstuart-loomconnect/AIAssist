Chat window

Where users talk to an agent, on a record page, the utility bar or mobile. Messages are saved first and answered asynchronously, so the window polls for the reply.

Behaviour worth knowing

  • While a reply is pending the window polls AIChatController.getConversationUpdate with a growing delay, and pauses when the browser tab is hidden.
  • A new reply is detected by a new agent message arriving, so Regenerate and retry keep the old reply visible until the new one is saved.
  • A refused send shows as an error with text from a Custom Label.
  • Screen Flow workflow actions open in a modal and run as the user.
