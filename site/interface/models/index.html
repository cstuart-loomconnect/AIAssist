AI Models

Manage connections to AI providers. A model is only switched on after a test message succeeds.

Behaviour worth knowing

  • The connection test runs the real chat path with a stand-in agent and a small token cap, so it works for every provider.
  • Switching a model off requires each active agent using it to be moved to another active model.

Objects it works with

  • AI Model Configuration AIModelConfiguration__c
  • AI Agent AIAgent__c
