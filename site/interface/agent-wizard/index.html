Agent Wizard

A step-by-step builder to create, copy and edit agents: basics, model, tools, access, limits, conversation behaviour and a review.

Behaviour worth knowing

  • Links to data sources and workflow actions default to inactive and the runtime reads only active links, so the wizard sets them active.
  • Access Mode defaults to Assigned Users Only; a user must also have an active usage policy to send messages.
