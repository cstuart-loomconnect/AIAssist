User interface

The chat window for users and one tab per admin area.

Chat windowWhere users talk to an agent, on a record page, the utility bar or mobile. Messages are saved first and answered asynchronously, so the window polls for the reply.Agent WizardA step-by-step builder to create, copy and edit agents: basics, model, tools, access, limits, conversation behaviour and a review.AI ModelsManage connections to AI providers. A model is only switched on after a test message succeeds.Prompt TemplatesWrite, publish, archive and try out the system prompts that agents answer with, including merge fields.AI ToolsData sources (information the model can fetch) and workflow actions (things it can suggest or do), each built with a guided wizard and tested before use.AI PoliciesUsage limits live on policies; a policy is assigned to users, and a check-a-user tool shows what applies to someone.PII RegistryChoose which objects are scanned, review how each field is classified, test masking, and see unprotected fields.AI Assist SettingsOrg-wide behaviour and appearance settings, with Org-wide, Profile and User levels.
